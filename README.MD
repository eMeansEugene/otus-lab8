# bayan — поиск файлов-дубликатов

Утилита командной строки для поиска файлов с идентичным содержимым. Сравнение выполняется лениво, по блокам: каждый блок каждого файла читается с диска не более одного раза.

## Сборка

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

Требования: C++20, CMake 3.20+, Boost (program_options, regex, crc, uuid).

## Использование

```bash
./bayan -d /path/to/dir1 /path/to/dir2 -b 4096
```

## Параметры

| Короткий | Длинный       | Описание                                           | По умолчанию |
|----------|---------------|-----------------------------------------------------|--------------|
| `-d`     | `--dirs`      | Директории для сканирования (одна или несколько)     | обязательный |
| `-e`     | `--exclude`   | Директории-исключения (полные пути)                  | —            |
| `-n`     | `--depth`     | Максимальная глубина вложенности (0 — без вложенных) | 0            |
| `-s`     | `--min-size`  | Минимальный размер файла в байтах                    | 1            |
| `-m`     | `--mask`      | Маски имён файлов (glob, регистронезависимые)        | все файлы    |
| `-b`     | `--block-size`| Размер блока чтения в байтах                         | обязательный |
| `-a`     | `--algo`      | Алгоритм хэширования: `crc32` или `md5`             | crc32        |
| `-h`     | `--help`      | Показать справку                                     | —            |

## Формат вывода

Полные пути файлов-дубликатов, по одному на строку. Группы дубликатов разделены пустой строкой.

```
/path/to/file_a.txt
/path/to/file_b.txt

/path/to/image1.png
/path/to/image2.png
/path/to/image3.png
```

## Примеры

Сканировать одну директорию, блок 1024, алгоритм MD5:

```bash
./bayan -d /home/user/documents -b 1024 -a md5
```

Сканировать с вложенностью до 2 уровней, исключить build, только текстовые файлы:

```bash
./bayan -d /home/user/project -n 2 -e /home/user/project/build -m "*.txt" -b 4096
```

Несколько директорий, минимальный размер 100 байт:

```bash
./bayan -d /tmp/dir1 /tmp/dir2 -s 100 -b 512
```
