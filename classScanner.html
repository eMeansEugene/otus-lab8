Detailed Description

Обходит указанные директории, фильтрует файлы и группирует их по размеру.

Scanner выполняет рекурсивный обход директорий с контролем глубины вложенности, исключением указанных директорий и фильтрацией по маскам имён и минимальному размеру. Результат — вектор групп файлов одинакового размера (кандидаты на дубликаты).
